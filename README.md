# DAYFLOW — Personal Command Center

A local-first productivity dashboard built with vanilla HTML, CSS and JavaScript.

## Run it
1. Extract the `DAYFLOW` folder.
2. Open `index.html` in a modern browser.
3. Start adding tasks and projects.

No installation, backend, account or API key is required. An internet connection is only needed if you want the optional Google Fonts to load; the app itself works offline once the files are on your device.

## Features
- Dashboard overview with today's task totals and completion progress.
- Daily task manager: add, edit, delete, prioritize, add notes, complete tasks, and browse previous/future dates.
- Project manager: add, edit, delete, set status, progress and optional deadline.
- Reports: completed vs pending chart for the last 7, 14 or 30 days.
- JSON export and import.
- Responsive layout for desktop and mobile.
- Data stored in this browser using localStorage.

## Important data note
Your data is stored in the browser profile on this device. It is not synced to other browsers or devices. Clearing browser site data, using private browsing, or resetting the browser may erase it. Use **Settings → Export backup** regularly.

## Files
- `index.html` — app structure
- `style.css` — visual design and responsive layout
- `app.js` — app logic, local persistence and charts
